# NCPSSD 期刊论文简报

本 skill 自带全部脚本与配置（`scripts\`），数据目录仍是项目根 `D:\D2\study\dsh\ncpssd\`。**核心约定：以刊为单位，一次只处理一本期刊，处理完（写 DONE 标记）才允许开始下一本；一本之内，先归类遍（全部归完）、后写作遍（逐篇追加），两遍不交错。**

## 固定路径

本文件中出现的 `scripts\...` 均相对本 skill 目录（记为 `<skill>`，即 `<项目>\.dsh\skills\ncpssd-briefing\`）；凡 `<数据目录>\...` 均指 `D:\D2\study\dsh\ncpssd\`。

- 数据目录：`D:\D2\study\dsh\ncpssd\`
- 采集脚本：`scripts\collect.py`（仅 Python 标准库；串行；自带网络重试；**每次运行无记忆**，不与任何历史数据比较）
- 配置：`scripts\config.json`（每刊 `name`/`gch`/`freq`/`short`/`months`；**以配置为准，不硬编码期刊**）
  - `short`：期刊代号（如 `jjyj`），用作采集子目录名与简报文件名。
  - `months`：相对运行月 M 的偏移列表，如 `[2, 3]` = 采 M-2、M-3 两月映射的各期。
- 采集结果：`<数据目录>\snap\<short>\`（重采某刊只清空该刊目录，其他刊原样保留）
  - `manifest.json`：该刊 `issues` 清单与 `entries` 元数据（含 `file` 指向单篇文件）。
  - `articles\NN.md`：**逐篇单文件**——判类与写简报时一次只读一篇，不要整读 manifest 的全部 entries。
  - `papers.md`：易读版，仅供人工核对，写简报时不必读。
  - `classified.jsonl`：归类遍结果（执行者写，步骤 3；逐行一篇 `{n,cat,keep}`，cat 逐字取 AI或LLM／财税／宏观／其他 之一；重采该刊时随目录清空重建，属预期）。
- 批次进度表：`<数据目录>\snap\state.md`（由执行者维护，collect.py 不读不写）
- 简报输出：`<数据目录>\reports\{YYYYMMDD}\briefing_{short}_{YYYYMMDD}.md`（每刊一份；`{YYYYMMDD}` 为批次启动日，记在 state.md 头部，续跑沿用）。**每批建一个日期文件夹，本批简报与下游播客 skill 的稿/音频同放其中。**

## 批次与断点续作

`snap\state.md` 格式（每刊一行，严格按 config 顺序）：

```markdown
# 批次 20261019
| 期刊 | short | 状态 | 简报 | 备注 |
|---|---|---|---|---|
| 经济研究 | jjyj | 完成 | reports\20261019\briefing_jjyj_20261019.md | 20/44 篇入选 |
| 管理世界 | glsj | 写作中 12/31 | ... | |
| 数量经济技术经济研究 | sljj | 无数据 | — | 两期均 empty_toc |
| 财贸经济 | cmjj | 待处理 | — | |
```

- 状态取值：`待处理` / `采集中` / `归类中 n/N` / `写作中 n/N` / `完成` / `无数据` / `失败(原因)` / `跳过(用户指定)`。
- **用户指定范围时**：只处理点名的刊，其余刊的 state 行置 `跳过(用户指定)`（备注写用户原话大意），串行循环视同完成态越过；不要拿"待处理"占位硬绕门禁。
- **批次启动判定**：`state.md` 不存在，或其头部批次号 ≠ 今天 → 新批次：删除 `snap\` 下全部内容（旧目录与残留杂项一次清掉），按 config 写全新 state.md（全部`待处理`）。存在且批次号一致且有未完成行 → 续跑，不删任何东西。
- 完成判据以**文件为准**：简报末尾有 `<!-- DONE ... -->` 行即视为该刊完成；state.md 与文件不符时，把 state.md 改对再继续。
- **归类遍未完的续跑**：比对 `classified.jsonl` 的 `n` 与 manifest `entries` 篇数——`n` 未恰好覆盖 1–N（缺行、或重号/缺号）=步骤 3 未完遍：缺号从最小缺号续批（无重号时即最后 NN 的下一篇），重号按步骤 3 消重；归完才许建骨架/写条目。
- 续跑`写作中`的刊：打开该刊简报，以最后一个 `---` 为界——其后若有半截条目（未到 `---` 就中断的），删除半截，但**保留紧跟其后的 `<!--END-…-->` 标记**，从对应篇号（classified.jsonl 里该节最后已写 `n` 的下一篇 `keep=true` 篇）继续往后写。

## 执行步骤（逐刊串行循环）

对 state.md 中第一个非`完成`/`无数据`/`失败`/`跳过`的期刊，依次执行下面 1-6 步；**该刊写完 DONE 之前，禁止碰下一本刊**。全部刊处理完执行第 7 步。

1. 采集该刊：
   ```
   python <skill>\scripts\collect.py --journal <刊名或short>
   ```
   输出 `done: <short> ok=x/y (...)`。**整刊 0 篇成功时脚本非零退出**：等 30 秒重跑一次，再失败则读该刊 `manifest.json` 的 `issues`——全是 `empty_toc` → state 记`无数据`；有 `error` → 记`失败(原因)`；两种情况都不写该刊简报，然后回到本步处理下一本刊。
2. 读 `<数据目录>\snap\<short>\manifest.json`：
   - `window` / `target_months` / `window_note`：该刊窗口月、实际采集年-月、撞期去重说明。
   - `issues`：逐期 `year`/`month`/`issue`/`status`/`count`。`empty_toc`=该期网站未收录；`mismatch`=返回期号与请求不符（数据已弃用）；`error`=采集失败。**缺哪期就在简报里注明哪期，不改 months、不补其他月份。**
   - `entries`：只用其 `file` 字段建立"篇号 → articles\NN.md"队列；**不要逐条通读 entries 里的摘要全文**。
3. **归类遍（该刊全部篇目先归完类，才开始写）**。硬性次序：entries 里每一篇都判完类并写入 `snap\<short>\classified.jsonl` 之后，才许进第 4 步建骨架——**不许归一半就开写**（2026-10-22 补条款，与 RePEc 期刊轨两遍制对齐）。按 NN 序读 `snap\<short>\articles\NN.md`，**每批 5–10 篇**，只用标题、关键词、摘要判类（本遍只判类、不写任何简报条目），按下面**固定文字**判断（判据模板已存档，不许随手微调，否则批间类别波动会被误读成学术风向变化；2026-10-22 版把 AI 提到最前，取代原财税优先序）：

   > 把每篇论文归入**且只归入**一个类别——按优先序自上而下判，**先命中即停**：
   > - **AI 或 LLM 方法**：方法上使用深度学习（神经网络）、强化学习、大语言模型、自然语言处理等 AI 技术的论文，或以这些技术本身为研究对象的论文；注意"数据要素""数字化"题材本身不算，除非确实使用或研究上述技术；
   > - **财税**：以财税作为研究主题的论文；
   > - **宏观**：方法上使用 RBC、DSGE、HANK 等宏观模型的论文；不含 CGE，不含空间一般均衡。
   > 三类皆不贴→归**其他**（keep=false，**不写入简报**，只计数）。同时贴合多类的归**靠前一类**，其余命中维度在该篇简介末尾括注（见"每篇条目模板"）。语义判断，不做关键词硬匹配。

   每批结果**回显 NN 对位**，逐行追加写入 `snap\<short>\classified.jsonl`（**逐行一篇、无表头**；`n`=该篇 NN，队列序即 manifest `entries[].file` 序；**`cat` 逐字取四个短名之一：AI或LLM／财税／宏观／其他——判据类名与 `## AI 或 LLM 方法` 节标题里的"方法"二字不进文件；第 4 步统计行的"AI-LLM"、DONE 行的"AI"只是展示简称，同样不进文件**；**`keep`=cat 属前三类（true），cat=其他则 false**）：
   ```json
   {"n": 7, "cat": "AI或LLM", "keep": true}
   ```
   某篇对不上位→单独退回逐篇重试。批与批之间串行，一次只做一批。**完遍判据=classified.jsonl 的 `n` 恰好覆盖 1–N**（N=entries 篇数，每号一行、不缺不重；不只是"行数相等"——逐篇重试丢行或重复追加都能让行数对上而覆盖没对上）。不满足=未完遍：缺号→从最小缺号续批；重号→保留正确行（两行 cat/keep 不一致时重读该篇按判据重判取舍）、删除多余行，直至每号一行（§批次与断点续作）。发现判类判错：回改 classified.jsonl 该行即可，不许带错进写作遍。
4. **建简报骨架**，一次写入 `<数据目录>\reports\{YYYYMMDD}\briefing_{short}_{YYYYMMDD}.md`（日期文件夹不存在则先创建）：标题（刊名+批次日期）、一句本批覆盖月份的说明（含 `window_note`）、期次表（刊名、年-期、出版日期、篇数；未收录/失败期注明。manifest `issues` 里没有出版日期——先填 `待核`，读完单篇后用篇头"（出版日期 YYYY-MM-DD）"回填，这是预期两步，不算返工）、**统计行按 classified.jsonl 计数直接写全**（不再是`统计: 待补`占位）：`统计: 本期刊 X 篇，其中 AI-LLM z / 财税 x / 宏观 y 共 m 篇已介绍，另 X−m 篇不属于这三类未介绍`（X=entries 篇数，m=x+y+z），以及三个小节——**小节次序=归类优先序，AI 在前；每个小节标题下写一个该节独有的收尾标记**，后续追加全靠它定位：

   ```
   ## AI 或 LLM 方法
   <!--END-AI-->

   ## 财税
   <!--END-财税-->

   ## 宏观
   <!--END-宏观-->
   ```
5. **逐篇追加（写作遍）**，这是主体循环，每次只处理一篇：
   - 从 classified.jsonl 按 NN 序取下一篇 `keep=true` 的篇目，**重读**该篇 `snap\<short>\articles\NN.md`（不凭归类遍的记忆写正文），三段写完再落盘；
   - 用**换收尾标记**的方式追加到所属小节的末尾：替换目标只允许是该节的 `<!--END-…-->` 标记（全文件唯一；不要用 `## 小节名` 当锚点——标题不唯一时会插错节），替换内容为"完整条目模板（自带结尾 `---` 与空行；多归篇目含括注行，见模板节）+ 该标记本身"。**条目模板必须整段照抄'每篇条目模板'，结尾的 `---` 是条目的一部分**，缺了它断点续作就无法定位；
   - "其他"（keep=false）不写入文件——其计数已在第 4 步统计行体现（X−m）；写作遍**不改类**，若确需改判，回步骤 3 改 classified.jsonl 对应行，再决定该篇是否补写/删除；
   - 一篇写完核对无误（期刊年月、归类落节、括注、无编造）再写下一篇。**state.md 不必每篇更新**：每读完 5–10 篇的 checkpoint 及第 6 步收尾时，把该行批量刷成 `写作中 n/N` / `完成` 即可——篇间进度以简报文件自身的条目与 `<!--END-…-->` 位置为准，state.md 只是粗粒度指示。
6. 收尾该刊：删除三行 `<!--END-…-->` 标记；重读自己写的简报，数出三节条目数**核对与 classified.jsonl 计数一致（AI z/财税 x/宏观 y）**，统计行与实况不符时以简报条目与 classified 逐行对位为准查因修正；期次表不得残留 `待核`——某期篇目全部 keep=false 时写作遍没读过它，但归类遍读过该期全部篇目，重读其中任一篇 `articles\NN.md` 篇头取出版日期回填；在文件末尾追加 `<!-- DONE YYYYMMDD 共X篇 AI z 财税x 宏观y 其他w -->`；state.md 置`完成`。**然后才回到本大步处理下一本刊。**
7. 全部期刊完成后最终答复：各刊采集篇数与入选篇数、各简报完整路径、`无数据`/`失败`的刊及原因、`跳过(用户指定)`的刊名单、缺期（empty_toc/mismatch）名单。

## 每篇条目模板

```markdown
### 论文标题
出处：经济研究 2026年第7期

**研究问题：** 一段通俗中文。

**方法要点：** 一段通俗中文。

**主要结论：** 一段通俗中文。

（另涉财税、宏观）

---
```

- 三段用行首粗体标签，**段与段之间只空一行、不分隔**；`---` 只出现在每篇条目末尾，用作篇间分隔与断点定位。
- **括注行只有多归论文才写**：该行论文落在靠前类小节下，同时在"主要结论"之后补一行 `（另涉…、…）` 列出其余命中维度；只命中一类则不写此行。
- 简介只依据该篇 `摘要` 与 `关键词`，不得编造数字或结论；出处行必须写明期刊与年月。

## 约束

- 所有网络访问交给 `collect.py`；不要自己另找资料来源。只做 HTML/文本拉取，不要截图；不抓全文、不读论文原文。
- 串行执行；不要派出子代理；**一次只推进一本刊、一次写入只含一篇条目**。
- **两遍不交错（单刊内次序固定）**：步骤 3 的完遍判据未满足（classified.jsonl 的 `n` 恰好覆盖 1–N，每号一行、不缺不重）之前，不许建骨架、不许写任何简报条目；写作遍不改类，改类回步骤 3 改 classified.jsonl 对应行后再续（2026-10-22 补，对齐 RePEc 期刊轨）。
- 运行期间不修改 `scripts\collect.py` 与 `config.json`；期刊、窗口（months）、缩写的调整属于维护，见下节。`<数据目录>\reports\` 的历史批次文件夹不动；本批一切产出只写进本批的 `reports\{YYYYMMDD}\`（该文件夹内播客的稿/音频由播客 skill 追加，本 skill 不碰）。
- **无记忆**：简报只依据本批 `snap\<short>\` 的结果；`state.md` 只服务当前批次（断点续作用），不承载跨批信息；不存在跨期去重，同一篇论文落在窗口内下次会再次介绍，属预期行为。新批次启动时按上文规则清场。
- `snap\` 下 `state.md` 与 `classified.jsonl` 由执行者写；各 `<short>\` 目录的清空由 `collect.py` 负责，除"新批次清场"外不要手工删除或移动任何文件。
- 简报为纯 Markdown；文件名 = `briefing_` + 刊 `short` + `_` + 批次日 `YYYYMMDD` + `.md`。

## 维护与排查

- **增加或更换期刊**：只改 `scripts\config.json` 的 `journals`（`name` / `gch` / `freq` / `short` / `months`，`freq` 取 `monthly`、`bimonthly`、`quarterly`；`short` 用小写字母，全局唯一）。gch 是站内期刊编号，可用 `scripts\_resolve_gch.py` 的同一思路获取：`https://m.ncpssd.cn/journal/list?page=N` 共 127 页、每页 20 种、按拼音排序，扫到刊名后取 `gch=` 值。
- **调整某刊窗口**：只改该刊 `months`。双月刊/季刊若两月映射同一期号，脚本自动去重并在 `window_note` 注明（如 经济学（季刊） [2,3] 实际只采一期）。
- **逐刊篇数核对**：`python <skill>\scripts\_audit_issues.py` 遍历 `snap\*\manifest.json` 打印各刊各期 `count`、`status` 与 `toc_ratio`（目录页文章链接数与文章数的比值，正常为整数倍，当前为 2；非整数说明页面结构变了、可能漏项）。
- **目录页原始审计**：`python <skill>\scripts\_audit_toc.py` 解析 `snap\*\raw\toc__*.html`，打印各页 data-id 数与 openDetail 链接数。
- **采集诊断**：`python <skill>\scripts\collect.py --probe`（可加 `--journal X`）打印各刊窗口年份已上线期号与最新一期样例，不写各刊采集目录。
- **单刊单期测试**：`python <skill>\scripts\collect.py --journal <name> --year <年> --month <月>`（或 `--issue <期>`），会清空并重写该刊目录；如需正式简报，测完按执行步骤重采该刊即可。
- **数据目录可覆盖**：设置环境变量 `NCPSSD_ROOT=<路径>` 可让脚本把 `snap/reports` 写到别处（默认自动识别项目根）。
